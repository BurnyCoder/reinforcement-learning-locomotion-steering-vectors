# Featured Ant lateral steering vector: ant-classic-005

The locked lateral vector at −0.1 changes mean sideways speed by **+0.40238 m/s**, paired 95% interval **[+0.30803, +0.49127]**, while retaining **96.83%** of forward speed on thirty fresh confirmation pairs. Failures remain **4/30 in both arms**. The numerical effect, movement and allowed quality-increase thresholds pass; the additional strict rule rejecting any episode ending before intervention does not. Seed 520025 ends at step 34 identically in baseline and all selected treatments. The preserved outcome is `confirmation_failed`; there was no replication or application.
