# Sources and reuse audit

Audited September 2026, with additions on 2026-10-16, corrections from the 2026-10-22 [fact-check](../reports/fact-check-2026-10-22.md), and an Ant-only source/interpretation update on 2026-10-29. Links below distinguish what the source establishes from this project's adaptation. Runtime compatibility claims require actual local checks; a generic API signature alone is insufficient. The [documentation audit](../reports/documentation-audit.md) records the checked claims, corrections, and verification limits.

The inspected checkpoint metadata records seed 0 for both policies. The pinned upstream [training loop](https://github.com/Farama-Foundation/minari-dataset-generation-scripts/blob/e74f9d0524c6df014c5a9985d0804001b9ce40dc/scripts/mujoco/train.py#L135-L173) uses SB3 learning in simulator environments and supports multiple runs; the [upload script](https://github.com/Farama-Foundation/minari-dataset-generation-scripts/blob/e74f9d0524c6df014c5a9985d0804001b9ce40dc/scripts/mujoco/upload_model.py#L23-L47) uploads `run_0/best_model.zip`, the best-evaluation model that the training loop's `EvalCallback` saves for seed 0, not the final model. Consistent with this, the checkpoints' recorded `num_timesteps` (5.92 million for HalfCheetah, 8.77 million for Ant) are below the training lengths stated on the Minari dataset pages (6×10⁶ and 10⁷ steps). These sources support attribution to upstream RL, not an independently reconstructed history of every upstream run or checkpoint-selection decision. This project evaluates one checkpoint per policy and verifies its bytes and inference behavior.

The [official HalfCheetah episode-end documentation](https://gymnasium.farama.org/environments/mujoco/half_cheetah/#episode-end) and [pinned environment implementation](https://github.com/Farama-Foundation/Gymnasium/blob/v1.0.0/gymnasium/envs/mujoco/half_cheetah_v5.py) establish that ordinary HalfCheetah episodes do not terminate merely because locomotion fails physically. They do not prescribe this project's quality thresholds. The [002 validation inspection](../reports/hc-running-002-validation-inspection.md) motivated classifying physical failure per episode before averaging failure frequency: post-onset inversion or forbidden-contact fraction above 5%, combined with existing explicit failures. The 5% episode cutoffs and maximum five-percentage-point failure increase are project pilot choices. This measurement revision was registered before selection/confirmation; old derived validation estimates and original trajectories are retained for audit.

## Why Baukit is the initial intervention dependency

[Baukit's pinned Trace implementation](https://github.com/davidbau/baukit/blob/9d51abd51ebf29769aecc38c4cbef459b731a36e/baukit/nethook.py) accepts an arbitrary PyTorch module, captures output, allows a differentiable `edit_output` callable, and removes its forward hook on context exit. That interface fits repeated ordinary SB3 predictions without tokenization or a different model-execution API. This project reuses that implementation and owns only the locomotion-specific wrapper and experiment logic.

[Package metadata](https://github.com/davidbau/baukit/blob/9d51abd51ebf29769aecc38c4cbef459b731a36e/setup.cfg) advertises Python >=3.7, OS independence, and an MIT classifier. The repository does not supply a full root LICENSE file at that revision, and GitHub's license detector returned no recognized license during this audit. This is documented provenance, not a claim that license text was verified. The [pinned commit](https://github.com/davidbau/baukit/commit/9d51abd51ebf29769aecc38c4cbef459b731a36e) is dated 22 February 2024. Package import also loads Torchvision, so Torch and Torchvision are pinned together.

Alternative libraries were inspected before selecting the integration:

| [pyvene](https://github.com/stanfordnlp/pyvene/tree/9e333904dcf9e597ca76170010d17f4d4580de8d) | Generic interventions and built-in [activation addition](https://github.com/stanfordnlp/pyvene/blob/9e333904dcf9e597ca76170010d17f4d4580de8d/pyvene/models/interventions.py); [Apache 2.0 license](https://github.com/stanfordnlp/pyvene/blob/9e333904dcf9e597ca76170010d17f4d4580de8d/LICENSE) | Useful for richer trainable/composed interventions, but requires more model-adapter and dependency work for the first frozen MLP experiment |

The pinned combination has now been exercised locally on Windows/Python 3.12 with both checkpoints and through the real SB3 prediction path. One integration issue required a small adapter: Baukit's optional-argument helper treats bound methods differently from plain functions, so the managed intervention passes a plain lambda that calls its editing method. This preserves reuse of Baukit's hook implementation. The integration tests cover batched shape handling, zero-strength identity, changed actions under an intervention, and hook removal on both success and exception.

PyTorch's own [forward-hook API](https://docs.pytorch.org/docs/stable/generated/torch.nn.Module.html#torch.nn.Module.register_forward_hook) is the minimal maintained fallback if the selected dependency later proves unsuitable. Avoid rebuilding a general intervention framework.

The [documentation audit](../reports/documentation-audit.md) uses independent [NumPy means](https://numpy.org/doc/1.26/reference/generated/numpy.mean.html), [linear quantiles](https://numpy.org/doc/1.26/reference/generated/numpy.quantile.html), and paired-episode index resampling to check saved evidence without calling production extraction/statistics or simulation. It compares historical gates as metadata rather than selecting treatments again. The publication checker uses the [Hugging Face inventory API](https://huggingface.co/docs/huggingface_hub/package_reference/hf_api#huggingface_hub.HfApi.model_info), public HTTP reads and standard-library hashes. The [pytest import-path documentation](https://docs.pytest.org/en/stable/explanation/pythonpath.html) supplies the minimal test configuration fix for importing repository audit scripts through the documented `pytest` entry point.

The [scientific-rigor audit](../reports/scientific-rigor-audit.md) reuses the production estimators and adds three standard tools.
- **Randomization test.** A paired sign-flip test, which is what [SciPy's `permutation_test`](https://docs.scipy.org/doc/scipy-1.14.1/reference/generated/scipy.stats.permutation_test.html) calls `permutation_type="samples"`. Its Monte Carlo p-value is (b+1)/(m+1), following [Phipson & Smyth](https://arxiv.org/abs/1603.05766), so it is never zero.
- **Odd/even decomposition.** An exact algebraic split of the responses at ±α into sign-dependent and sign-independent parts.
- **Monte Carlo rank test and paired sample size** (used by the [world-Y specificity audit](../reports/ant-classic-005-y-shift-audit.md)).
  - The rank test is Barnard's Monte Carlo test as reviewed in [Myllymäki et al., *Global envelope tests*](https://arxiv.org/pdf/1307.0239): the observed statistic is ranked among s+1 values, giving p = (1 + #≥)/(s+1) with ties counted as extreme. This is the same form as the Phipson & Smyth rule.
  - Sample size uses the paired normal approximation n = ((z₁₋α/₂ + z_power)·σ_d/δ)², following the [CBU statistics wiki](https://imaging.mrc-cbu.cam.ac.uk/statswiki/FAQ/power/onesamp). It slightly underestimates exact paired-t sample sizes. Quantiles come from Python's [`NormalDist.inv_cdf`](https://docs.python.org/3.12/library/statistics.html#statistics.NormalDist.inv_cdf).
  - Heading time courses use [`numpy.unwrap`](https://numpy.org/doc/1.26/reference/generated/numpy.unwrap.html).
- **Weak-null reading of the sign-flip test and shared-seed variance** (used by the [path-mechanism audit](../reports/ant-classic-005-mechanism-audit.md)).
  - Exact sign-flip calibration requires symmetry/exchangeability under the sign changes; a zero-mean null alone is insufficient. Without that symmetry, the mean-based test has an asymptotic weak-null interpretation under the relevant regularity conditions (Romano 1990, *JASA* 85:686–692, as reviewed by [Ritzwoller, Romano & Shaikh](https://arxiv.org/abs/2406.09521)). This does not establish finite-sample exactness for Ant.
  - `sign_flip_pvalue(..., studentized=True)` divides each relabeled mean by its own standard error, following [Chung & Romano 2013](https://arxiv.org/abs/1304.5939).
  - Monotonicity and continuity conditions can give sufficient guarantees for common-random-number variance reduction ([Glasserman & Yao 1992](https://doi.org/10.1287/mnsc.38.6.884)); they are not necessary conditions, and they have not been established for this experiment. The audit measures the baseline–treated correlation instead of assuming a gain, without equating weak correlation with independence.
- **Second-order optimality conditions.** At an interior local maximizer of a twice-differentiable unconstrained objective, the gradient is zero and the Hessian is negative semidefinite ([lecture notes](https://ee.iitm.ac.in/uday/notes/opt/uo.html); Nocedal & Wright, *Numerical Optimization*, 2nd ed., ch. 2). Applying this to an activation offset requires a local maximum along that intervention path. A trained return objective does not establish local optimality of deterministic evaluation velocity. This motivates a post hoc hypothesis, not evidence for it.

The [independent Ant audit](../reports/ant-classic-005-independent-audit.md) adds a perception intervention and pinned SciPy statistics.

The further claim review uses [Cawley and Talbot (2010)](https://jmlr.csail.mit.edu/papers/volume11/cawley10a/cawley10a.pdf), particularly Sections 4–5, for selection bias from optimizing noisy validation criteria. That source does not establish the cause of this project's validation-to-confirmation decrease. A covariance participation ratio is also distinct from [matrix rank](https://numpy.org/doc/1.26/reference/generated/numpy.linalg.matrix_rank.html); shared activation span alone guarantees neither leading-component confinement nor large cosine alignment.

- **Observation layout.** [Gymnasium Ant-v5 `_get_obs`](https://github.com/Farama-Foundation/Gymnasium/blob/v1.0.0/gymnasium/envs/mujoco/ant_v5.py) concatenates `qpos[2:]`, `qvel` and `cfrc_ext[1:]` clipped to the contact-force range. That puts the torso quaternion at obs[1:5], free-joint velocities at obs[13:19] and 13 × 6 contact wrenches at obs[27:105].
- **Frames.**
  - MuJoCo's ["c"-quantities](https://mujoco.readthedocs.io/en/3.1.5/computation/index.html) are expressed "in a global frame centered at the subtree center of mass".
  - [`mjData`](https://mujoco.readthedocs.io/en/3.1.5/APIreference/APItypes.html) lists `cfrc_ext` in rotation:translation order.
  - The free joint's linear velocity is world-frame and its angular velocity body-frame. `tests/test_perception.py` establishes this with [`mj_objectVelocity`](https://mujoco.readthedocs.io/en/3.1.5/APIreference/APIfunctions.html#mj-objectvelocity). The pages consulted during the audit did not state it, but the [MuJoCo 3.1.5 overview](https://mujoco.readthedocs.io/en/3.1.5/overview.html#floating-objects) does: linear free-joint velocities are global-frame and rotational ones local-frame.
  - The physical-state comparison deliberately scales contact wrenches below clipping; it verifies the coordinate frames in that regime. Actual Ant observations have already lost saturated wrench values. The historical comparator computes `clip(R clip(f))`, whereas a physically yaw-rotated state's observation would contain `clip(R f)`. These are generally unequal, as the saturated-wrench regression test demonstrates. Quaternion and world-linear-velocity rotations remain exact. Keep the measured observation-intervention outcomes, but interpret the alignment and ablations as support for a heading-related perceptual account, not exact physical-state equivalence or a sole semantic mediator. See the [implementation and tests](../tests/test_perception.py), which preserve the original transform.
- **Statistics.**
  - SciPy 1.14.1 [`bootstrap`](https://docs.scipy.org/doc/scipy-1.14.1/reference/generated/scipy.stats.bootstrap.html) supplies the BCa and percentile intervals.
  - [`permutation_test`](https://docs.scipy.org/doc/scipy-1.14.1/reference/generated/scipy.stats.permutation_test.html) with one sample flips signs.
  - [`wilcoxon`](https://docs.scipy.org/doc/scipy-1.14.1/reference/generated/scipy.stats.wilcoxon.html) gives the signed-rank test.
  - The rank arithmetic follows [Phipson & Smyth 2010](https://doi.org/10.2202/1544-6115.1585); calibration additionally requires a justified null and exchangeability. Norm matching a selected contrast against random directions does not establish that assumption. [Project interpretation](methodology.md#statistical-assumptions-and-rank-interpretation).
  - The adjustment uses [Holm 1979](https://www.jstor.org/stable/4615733); its family-wise guarantee requires valid input p-values.
- **Rendering.** The paper renderer draws Greek letters with ReportLab's standard Symbol font and exponents with `<super>` [paragraph markup](https://docs.reportlab.com/reportlab/userguide/ch6_paragraphs/).

## Ant licensing and reuse limits

The maze papers and reports above are cited as prior ideas; no implementation code, weights, or illustrations were copied from them. Existing integration uses library APIs rather than vendoring their implementations. The pinned [Baukit package metadata](https://github.com/davidbau/baukit/blob/9d51abd51ebf29769aecc38c4cbef459b731a36e/setup.cfg) declares an MIT license classifier; that declaration is distinct from independently verifying a complete license grant for every artifact.

At the evaluated Ant checkpoint revision, the [Hub metadata and file inventory](https://huggingface.co/api/models/farama-minari/Ant-v5-SAC-medium/revision/de5978d34b0118341df2b0a30232c5d2bfcb148e) supplied no model-card license field or license file when checked on 2026-10-29. Checkpoint redistribution terms therefore remain unverified. Library licenses do not establish the weights' license. This project references the original checkpoint and publishes its own steering arrays, measurements and provenance; it does not repackage the upstream weights or assert a newly verified permission to redistribute them.

The [Ant seed-cohort ledger](../src/rl_locomotion_steering_vectors/seed_cohorts.json) is a project provenance repair, based on the original manifest and the recorded application-cohort collision. Its shared guard uses Python's [package-resource reader](https://docs.python.org/3.12/library/importlib.resources.html#importlib.resources.files) and set intersection. It protects application allocation and exact historical audit replay against these recorded reservations; it is not a complete registry of every project or future cohort.

## Related work reserved for later experiments

[Policy Gradient Steering](https://arxiv.org/abs/2607.27574v1) is a candidate escalation when natural contrast exists but classic vectors do not control the behavior. The published experiment pipeline does not integrate it. The paused prototype adapter ([`pgs-adaptation.md`](pgs-adaptation.md)) has unit tests but has not been run as an experiment. Continuous-action log probabilities and any trust-region/regularization machinery must be checked against the actual SAC/TQC distribution; categorical-language-model code is not directly interchangeable.

Command-conditioned HalfCheetah velocity is a possible online-RL training experiment, informed by [existing velocity-task wrappers](https://ut-austin-rpl.github.io/amago/_modules/amago/envs/builtin/half_cheetah_v4_vel.html). Training rewards, convergence criteria, and extraction pairs must be specified before that experiment and documented as adaptations.
